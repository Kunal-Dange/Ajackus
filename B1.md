# B1 — The Glacier cost gotcha

What's the actual cost impact of an early deletion after archival? How would you redesign the
lifecycle so this stops quietly costing more than budgeted?

In the lifecycle.tf , storage class is Glacier which means it has 90 day minimum storage duration.
The object transaction on day 30. If it is deleted on day 40, that means it has only spent 10 days in that storage class.
So AWS charges the normal storage usage plus deletion charges for the remaining 80 days of the 90 days. This will also depend on the region, size, storage rate of the bucket objects.


Redesign - 

Record the archival timestamp, storage class transition for each object.
On a deletion request, immediately make the listing and its photos inaccessible, revoke the access and make a deletion workflow with a deadline.
Calculate wheter the object is still inside the 90 day minimum. If it is , estimate the remaining early deletion charge and compare it with the cost of retaining it untill the minimun duration expires.
execute the physical deletion within the contract 30 day deletion.
Emit a structured audit event containing the key, version, and timestamp.
We can add alert on early deletion.
